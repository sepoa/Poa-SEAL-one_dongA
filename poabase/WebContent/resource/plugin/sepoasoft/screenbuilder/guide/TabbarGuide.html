탭바의 구조[편집]


  • 탭바는 사용자가 탭(tab)을 클릭했을 때 특정 화면이 나타나는 화면 전환 컴포넌트로 여러 셀(cell)들로 구성되어 있으며, 셀은 아이템(item)이라 지칭되기도 한다.
  • 한 페이지에 여러 셀들을 연결되어 있으며, 이러한 셀들 중 하나의 셀이 탭 클릭 시 화면에 나타난다.
  • 탭바는 주로 리스트들을 담는데 사용된다.


탭바의 생성[편집]

  • 탭바 생성
  1. template 태그 안에서 탭바가 위치할 div를 생성하고 div의 id 값을 설정한다.
  2. tabbar 태그를 통해 탭바를 생성하고 앞서 지정한 div의 id 값을 탭바의 div의 값으로 설정한다.
  3. 탭바 객체에 접근할 때 사용되는 고유값으로 id 값을 설정한다.
  • 셀/아이템 생성 및 설정
  1. 탭바를 구성할 개별 아이템들은 tabbar 태그 내에서 item 태그를 사용하여 생성한다.
  2. 각 아이템에 접근할 때 사용되는 고유값으로 id 값을 설정한다.
  3. item 태그 내에 attach 태그를 생성하고, attach 태그의 file 값으로 해당 아이템에 attach될 파일의 경로와 파일명을 설정한다.
  4. item 태그 내에서 selected 속성값을 'true'로 설정하면 화면 로드 시 해당 아이템이 화면에 default로 노출된다.
    1. 여러 아이템에 동시에 설정 시 처음에 설정한 아이템에 적용됨
    2. 참고 : 캐러셀에서는 사용자가 첫 번째로 노출될 아이템을 설정할 수 없음
  5. item 태그 내에서 name 속성값은 tab에 나타날 텍스트이며, 반드시 다국어지원 CODE로 입력해야 한다.

탭바 및 셀/아이템 접근[편집]

  • 탭바 객체 접근
  1. tabbar 태그에서 id로 설정한 값을 통해 탭바 객체에 접근할 수 있다.
  2. cells(셀 id) 함수를 통해 탭바 객체에서 개별 셀의 객체에 직접 접근할 수 있다.
  • 셀/아이템 접근
    탭바 객체에서 cells(셀 id) 함수를 통해 직접 개별 셀에 접근하거나, cells 함수의 결과값을 변수에 담은 후 사용할 수 있다.



  • 탭 클릭 이벤트 설정
  1. tabbar 태그 내에 onTabClick 이벤트를 설정하고 탭 클릭 시 발생할 함수를 정의한다.
  2. 탭을 클릭하면 정의된 함수에 클릭된 탭과 관련된 셀/아이템의 id가 자동으로 전달된다.
  3. 전달된 id를 이용하여 필요한 작업을 수행한다.

SUX XML 코드[편집]

<tabbar id="leftTabbar" div="tabbardiv">		<!-- id: 참조변수, div: Tabbar Templet div id-->
	<item id="tabbar1" name="AD_002.TITLE1">	<!-- tabbar1 이라는 아이템 하나를 등록하고 title로는 다국어에 등록된 text를 사용-->
		<list></list>				<!-- tabbar1에 list component를 Attach-->
	</item>
        <item id="tabbar2" name="AD_002.TITLE2">	<!-- tabbar2 라는 아이템을 하나더 등록한다.-->
		<grid></grid>				<!-- tabbar2에는 grid component를 Attach-->
	</item>
</tabbar>

Dhtmlx 기본제공 API

대분류 소분류 메소드명 비고

  • getTabsCount
    아이템의 전체 개수를 반환
number getTabsCount();

반환

number 아이템의 전체 개수

Example 

leftTabbar.getTabsCount();



  • _setTabActive
    특정 아이템을 활성화함
_setTabActive(item_id);

매개변수

item_id string or number 아이템 ID

Example 

leftTabbar._setTabActive('Tab1');  // ID가 'Tab1'인 아이템을 활성화함



  • _setTabText
    특정 아이템의 텍스트와 너비를 지정
_setTabText(item_id, text, width);

매개변수

item_id string or number 아이템 ID
text string 지정할 텍스트
width number 아이템 너비 (단위 : 픽셀)

Example 

leftTabbar._setTabText('Tab1', 'TEST_TAB', 100);  // ID가 'Tab1'인 아이템의 텍스트와 너비를 각각 'TEST_TAB', 100 픽셀로 지정



Event[편집]

  • onSelect
    boolean onSelect(mixed id,mixed lastId)
    이 이벤트는 DHTMLX에서 제공되는 기본 tabbar 이벤트로서 item click시 발생한다.
    return값으로 false 리턴시 select가 취소 
<tabbar id="Tabbar" div="tabbardiv">
	<item id="tabbar1" name="AD_001.TITLE1">
	</item>
	<item id="tabbar2" name="AD_001.TITLE2">
	</item>
	<event type='onSelect' callback='selectitem'/>
</tabbar>
function selectitem(id, lastId){
	if(id=='tabbar1'){
		return true;
	}else{
		return false;
	}
}
  • onTabChanged
    이 이벤트는 SUX 에서 custome된 이벤트로 tabbar의 아이템이 change된 이후 호출되는 이벤트이다.
    paramiter로는 item_id를 리턴받는다. 
<tabbar id="Tabbar" div="tabbardiv">
	<item id="tabbar1" name="AD_001.TITLE1">
	</item>
	<item id="tabbar2" name="AD_001.TITLE2">
	</item>
	<event type='onTabChanged' callback='changeditem'/>
</tabbar>
function changeditem(id){
	if(id=='tabbar1'){
		Alert(id+'선택됨');
	}
}
