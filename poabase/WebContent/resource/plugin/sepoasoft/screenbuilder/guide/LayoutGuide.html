SUX XML 코드[편집]

<?xml version="1.0" encoding="UTF-8"?>
<body header="false">
    <template>
    <![CDATA[
        <div class="container" id="container" style="overflow:hidden;">
            <div id="layoutBox" class="lowerDiv" style="width:100%;height:100%"></div>
        </div>
    ]]>
    </template>
    <layout div="layoutBox" id="containerLayout" pattern="2E">
        <cell>
	    <id>a</id>
            <cicon>
            	<btn id="menu"/>
		<btn id="save"/>
                <btn id="delete"/>
            </cicon>
            <header type="contents" text="MV_023.TITLE" />
            <width>400</width>
            <height>400</height>
            <collapse icon="true" collapsed="true" />
	    <fix_size>true,false</fix_size>
	    <attach file="/PurchaseRequest/PR/PrInfoForm.sux />
	</cell>
	<cell>
	    <id>b</id>
	    <fix_size>true,false</fix_size>
	    <attach file="=/PurchaseRequest/PR/PrInfoGrid.sux" />
	</cell>
    </layout>
    <onloadscript>
    </onloadscript>
    <scriptlet>
    <![CDATA[
    ]]>
    </scriptlet>
    <userscript>
    </userscript>
</body>


  • <layout> - div : layout이 작성될 div의 ID
  • <layout> - id : layout 객체의 변수명
  • layout pattern : layout의 화면 구성을 설정
  1. 화면은 가로와 세로 분할 방식에 따라 다양하게 구성될 수 있으며, 각 화면 구성 방식에 따른 layout pattern의 값은 아래 그림과 같다.
  2. 상위 xml 코드에서 layout pattern이 '2E'이기 때문에 화면은 세로로 2분할된 방식으로 구성된다.
    <레이아웃 패턴값에 따른 화면 분할>


  • <cell> : 전체 layout 화면을 구성하는 각각의 분할 화면을 cell이라고 지칭
  • <cell> - id : 각 cell을 지시하는 고유값으로 알파벳 소문자(a ~ z)로 값이 정해져 있으며 임의로 설정할 수 없음
  • <cell> - <header> - type : cell의 헤더부분 타입을 설정
  1. 설정값 : list, contents
  2. 미입력 시 기본 형태로 설정된다.
  • <cell> - <header> - text : cell의 헤더 부분에 나타날 텍스트를 설정
  1. 설정하려는 텍스트를 text의 값에 직접 입력하면 안되며 반드시 다국어관리에서 등록한 후 등록된 코드를 사용해야 한다.
  2. 다국어관리에 대한 자세한 사항은 다국어관리 문서참고
    <cell header text 값 설정 예시>


  • <cell> - <header> - view : cell의 헤더부분의 보기/숨김을 설정
  1. true 설정 시 헤더가 화면에 나타나고, false 설정 시 화면에 나타나지 않는다.
  2. text나 type 속성이 지정되어 있으면 자동으로 true가 되며, text, type이 지정되어 있어도 view의 값을 false로 설정하면 헤더가 화면에 나타나지 않는다
  • <cell> - <cicon> : 헤더에 나타날 버튼 설정
  1. button.js의 template에 layout_{btn id}로 등록된 버튼만 사용 가능하다.
  2. 버튼에 대한 자세한 사항은 Button 문서참조
    <버튼 설정 방법 예시>


  • <cell> - <icon> : 헤더 좌측에 icon으로 된 버튼을 생성
  1. <cicon>이 설정되어 있을 경우 동작하지 않는다.
  2. layout.css에 이미지 css가 등록되어 있어야 한다.
  • <cell> - <width> : cell의 너비 지정 (단위 : 픽셀)
  • <cell> - <height> : cell의 높이 지정 (단위 : 픽셀)
  • <cell> - <collapse> - icon : cell의 접기/펼치기 버튼 활성화 여부 설정
  1. true 설정 시 접기/펼치기 버튼이 활성화되며, false 설정 시 비활성화된다.
  2. 접기/펼치기 버튼은 셀의 헤더 최우측에 위치하는 화살표 모양의 버튼으로 클릭 시 해당 셀이 접히면서 화면에서 사라지며, 접힌 상태에서 클릭 시 셀이 펼쳐지며 화면에 나타난다.
    <접기/펼치기 버튼 예시>


  • <cell> - <collapse> - collapsed : cell의 접기/펼치기 기본값을 지정
  1. true 설정 시 화면을 로드하면 해당 셀이 접혀 있음 (Default 값 : false)
  • <cell> - <collapse> - text : cell이 접혀있을 때의 text를 지정
  • <cell> - <fix_size> : cell의 크기를 고정. 자세한 내용은 하단 링크 참조
  • <cell> - <attach> - file : cell에 보여줄 파일을 지정
  1. 파일명 : 파일의 실제 확장자가 xml이라도 attach file 속성에는 sux로 적는다.
  2. 경로 : 해당 프로젝트 - Poa-Package - sepoaux - xml 까지는 생략하고 이 후 경로만 적는다.
    ex) 파일 경로가 poa-management - Poa-Package - sepoaux - xml - UserManagement - UserMangementGrid.xml일 경우 
      <attach file = "/UserManagement/UserMangementGrid.sux" />
  • <cell> - <attach> - url : cell에 보여줄 파일을 지정
  1. file 속성을 사용하여 attach할 경우 해당 파일의 코드 자체가 attach되는 반면, url 속성을 이용하면 해당 파일이 iframe 방식으로 attach된다.
  • <cell> - <attach> - param : cell에 파일을 attach할 때 사용할 매개변수 지정
  1. a:1, b:2 의 형식이나, 현재 페이지로 넘어온 request를 그대로 다시 넘기고 싶을 때는 {}로 넘어온 매개변수의 ID를 입력한다.
autosize : layout-autosize 참조
fix_size : layout-fix_size 참조
pattern : layout-pattern 참조

  • attachURL
    셀의 attach file을 지정
attachURL(url);

매개변수

url string 지정할 파일의 경로 및 파일명

Example 

containerLayout.cells('a').attachURL('/admin/test.sux');  // ID가 'a'인 셀에서 '/admin/test.sux' 경로에 있는 파일을 attach file로 지정



  • changeHeaderIcon
    레이아웃 헤더에 등록된 아이콘 버튼을 활성화 여부 설정
changeHeaderIcon(id, mode, type);

매개변수

id(필수) string 셀 ID
mode string 'show'(활성화), 'hide'(비활성화)
type string 'filter', 'add', 'reject', 'delete', 'minus', 'update', 'copy', 'confirm', 'cancel', 'save' 등이 있으며 layout.css에서 등록

Example 

changeHeaderIcon('a', 'show', 'add, delete');  // ID가 'a'인 셀의 레이아웃 헤더에 등록된 아이콘 버튼 중 'add'와 'delete'를 활성화



  • changeHeaderText
    레이아웃 헤더에 텍스트를 설정
changeHeaderText(id, text);

매개변수

id(필수) string 셀 ID
text(필수) string 레이아웃 헤더에 보여질 텍스트

Example 

changeHeaderText('a', '환경설정');  // ID가 'a'인 셀의 레이아웃 헤더의 텍스트를 '환경설정'으로 지정



  • getButtonObject
    레이아웃에 있는 특정 버튼의 object를 반환
getButtonObject(id, btnId);

매개변수

id(필수) string 셀 ID
btnId(필수) string 버튼 ID

반환

object 버튼의 객체

Example 

var obj = getButtonObject('a', 'save');  // ID가 'a'인 셀에서 ID가 'save'인 버튼의 object를 반환

  • hideButton
    레이아웃의 펼치기/접기 버튼을 숨김 (펼치기/접기 버튼 : 레이아웃의 우측 상단에 위치한 화살표 모양의 버튼으로 누르면 해당 레이아웃이 접히고, 접힌 상태에서 다시 누르면 레이아웃이 펼쳐짐)
hideButton();

Example
